# メッセージ領域の緑枠を消す

1. 会話をスクロールして別のウインドウへ切り替え、戻ったときも含めて緑枠の表示を確認する。
2. メッセージ領域とその親要素について、切り替え前後の `outline`、`box-shadow`、`border` と適用元を調べる。
3. 枠を描いている要素に限定して `chatgpt.css` を修正する。
4. 同じ操作で緑枠が消えること、入力欄の枠とリンクやボタンのキーボードフォーカスが引き続き見えることを確認する。

## 調査・修正結果

別のウインドウから会話に戻ると、会話領域に重なる `peer-focus-visible/transcript:ring-2` クラスの要素が、緑色の内側の影で 2px の枠を描いていた。スクロール領域自体の `outline` と `box-shadow` を消した段階では再発した。

重なっている要素の `--tw-ring-shadow` を透明にし、緑枠が出ていた実画面で `box-shadow` の計算値から緑色の影が消えたことを確認した。同じ指定を `chatgpt.css` に反映した後、利用者からも改善したように見えるとの報告があった。入力欄、リンク、ボタンのフォーカス表示は個別には未確認。
