# 新規チャットの緑枠を入力欄に合わせる

Vivaldi の Web アプリでは、新規チャットの入力欄が角丸でも、緑の枠が四角く表示される。

1. 新規チャットで緑枠を描く要素と、入力欄の角丸を持つ要素のスタイルを確認する。
2. `chatgpt.css` の新規チャット用の指定を修正し、入力欄の輪郭に沿って緑の内枠を表示する。
3. Vivaldi で新規チャットの入力欄と既存の会話の入力欄を確認する。

## 調査・修正結果

新規チャットの外側の要素に従来の識別属性がなく、角丸を持たない要素に緑枠が付いていた。フォームの `data-composer-placement='home'` で新規チャットを判別し、角丸を持つ `data-composer-body` に緑の内枠を付けるようにした。

Vivaldi で拡張機能と ChatGPT を再読み込みし、新規チャットと既存の会話の両方で緑枠が入力欄の輪郭に沿うことを確認した。JavaScript とマニフェストの構文確認および `git diff --check` も通過した。今回の表示修正に残課題はない。
