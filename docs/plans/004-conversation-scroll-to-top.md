# 長い会話での先頭移動

`gg` で会話欄の先頭に移動し、履歴の追加読み込みで表示位置がずれたら先頭に戻す。手動操作や会話の切り替えで追従を終了する。

## 作業内容

- `gg` と `Shift+G` で会話欄のスクロール領域を選ぶ処理と、手動操作で追従を解除する処理を共通化した。
- `gg` で先頭に移動した後は、履歴の追加読み込みでスクロール位置が変わるたびに先頭へ戻す。キー入力、ホイール、クリック、タッチ、会話の切り替えで追従を解除する。
- README の `gg` の説明に、過去のメッセージを読み込みながら先頭へ移動することを明記した。

## 検証結果

Prettier で変更した 3 ファイルの整形を確認した。`node --check chatgpt.js`、`python3 -m json.tool manifest.json`、`git diff --check` はすべて通過した。

## 残課題

実際の ChatGPT で長い会話を初めて開き、1 回の `gg` で最初のメッセージに到達することと、手動スクロールで追従を解除できることは未確認。
