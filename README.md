# ChatGPT Vim

ChatGPT を Vim 風のキーバインドで操作する Chrome 拡張です。

## 操作

入力欄にフォーカスがないときの操作です。

新規会話から `/c/...` または `/uc/...` への URL 変更を検知して、
入力欄の自動フォーカスを解除します。
`i` / `s` または入力欄のクリックで入力を再開した場合は、フォーカスを解除しません。

| キー                | 操作                         |
| ------------------- | ---------------------------- |
| `j` / `k`           | 下 / 上に 100 px スクロール  |
| `gg`                | 先頭へ移動                   |
| `Shift+g`           | 末尾へ移動                   |
| `Ctrl+d` / `Ctrl+u` | 下 / 上 スクロール           |
| `i` / `s`           | メッセージ入力欄にフォーカス |
| `Ctrl+r`            | ページを再読み込み           |

メッセージ入力欄での操作です。日本語変換中は処理しません。

| キー                    | 操作                               |
| ----------------------- | ---------------------------------- |
| `Escape`                | 入力欄からフォーカスを外す         |
| `Enter` / `Ctrl+m`      | `Shift+Enter` を送出して改行       |
| `Shift+Enter`           | 通常の改行操作                     |
| `Ctrl+Enter` / `Ctrl+]` | 送信ボタンを押し、フォーカスを外す |

送信時はキーイベントの既定動作と伝播を停止し、ChatGPT 側のキー処理との重複を防ぎます。
入力欄のクリアは ChatGPT 側の送信処理に任せます。
