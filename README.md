# ChatGPT Vim

ChatGPT を Vim 風のキーバインドで操作する Chrome 拡張です。

## 操作

入力欄にフォーカスがないときの操作です。

新規チャットの初回送信後や、別の既存チャット（`/c/...` または `/uc/...`）に切り替えたときは、
入力欄の自動フォーカスを解除します。
`i` / `s` または入力欄のクリックで入力を再開した場合は、フォーカスを解除しません。

| キー                | 操作                         |
| ------------------- | ---------------------------- |
| `j` / `k`           | 下 / 上に 100 px スクロール  |
| `gg`                | 先頭へ移動                   |
| `Shift+g`           | 末尾へ移動                   |
| `Ctrl+d` / `Ctrl+u` | 下 / 上に 500 px スクロール  |
| `i` / `s`           | メッセージ入力欄にフォーカス |
| `Ctrl+r`            | ページを再読み込み           |

メッセージ入力欄での操作です。日本語変換中は処理しません。

| キー                    | 操作                                            |
| ----------------------- | ----------------------------------------------- |
| `Escape`                | 入力欄からフォーカスを外す                      |
| `Enter` / `Ctrl+m`      | `Shift+Enter` を送出して改行                    |
| `Shift+Enter`           | 通常の改行操作                                  |
| `Ctrl+Enter` / `Ctrl+]` | ChatGPT 標準の Enter で送信し、フォーカスを外す |

送信後に `Ctrl+Shift+O` で新しいチャットを開くと、空の入力欄から書き始められます。
