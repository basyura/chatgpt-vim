# ChatGPT Vim

ChatGPT を Vim 風のキーバインドで操作する Chrome 拡張です。
Tampermonkey 用スクリプトの処理を、Manifest V3 のコンテンツスクリプトとして移植しています。

## 導入

1. Tampermonkey に登録した元の ChatGPT スクリプトを無効にします（二重実行を防ぐため）。
2. Chrome のアドレスバーに `chrome://extensions` を入力します。
3. 「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選択します。
5. このリポジトリのフォルダ（`manifest.json` があるフォルダ）を選択します。
6. ChatGPT のタブを再読み込みします。

ビルドや依存パッケージのインストールは不要です。
更新時は拡張機能の一覧で再読み込みし、ChatGPT のタブも再読み込みしてください。

## 操作

入力欄にフォーカスがないときの操作です。

| キー | 操作 |
| --- | --- |
| `j` / `k` | 下 / 上に 100 px スクロール |
| `gg` | 800 ms 以内に 2 回押して先頭へ移動 |
| `Shift+g` | 末尾へ移動 |
| `Ctrl+d` / `Ctrl+u` | 下 / 上に 500 px スクロール |
| `i` / `s` | メッセージ入力欄にフォーカス |
| `Ctrl+r` | ページを再読み込み |
| `F12` | ブラウザ標準の操作 |

メッセージ入力欄での操作です。日本語変換中は処理しません。

| キー | 操作 |
| --- | --- |
| `Escape` | 入力欄からフォーカスを外す |
| `Enter` / `Ctrl+m` | `Shift+Enter` を送出して改行 |
| `Shift+Enter` | 通常の改行操作 |
| `Ctrl+Enter` / `Ctrl+]` | 送信ボタンを押し、フォーカスを外す |

元スクリプトの `]` 単独での改行動作も引き継いでいます。
また、URL に `prompt=` または `q=` が含まれる場合、初期化時に入力欄が空でなくなると送信ボタンを押します。

## 対象と制約

- 対象は `https://chatgpt.com/*` と `https://chat.openai.com/*` です。
- 入力欄の検出は元スクリプトと同じく日本語の `aria-label="ChatGPT に聞く"` を使用します。
- ChatGPT の画面構造や表示言語の変更により、入力・送信・スクロール操作が動かなくなる場合があります。
- 元スクリプトの `Ctrl+w` 抑止処理も維持していますが、ブラウザが優先するショートカットの抑止は保証できません。
- 追加の API 権限、バックグラウンド処理、外部ライブラリは使用しません。

構成は [Chrome のコンテンツスクリプト公式ドキュメント](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts) に準拠しています。
